# ADR-029 作品笔记与学习者画像
## 决策

“讲过什么”从 KP 检索；作品上下文与学习者偏好分别进入有界笔记。条数与长度由后端强制，用户可编辑删除；Agent 经工具读写。

## 理由与取舍

平行散文记忆会与知识库漂移。注入可能避免重复，也可能使讲解过度省略，需实验。MVP 无语法模式自动匹配，不能承诺语法都能被自动召回。

旧 note_ops 回合约束由统一笔记工具替代；当前内容可更新，不要求永久版本化每次命中时间。
