# ADR-013 Anki 导出保留显式选择
## 决策

导出前让用户选择条目、字段映射及外部发送；站内安排复习与外部导出分开。

导出以 ReviewItem／Occurrence 为来源。每次已保存或已发送的导出快照至少固定 `review_item_id`、`occurrence_id`、字段映射、被引用的解析小节版本和媒体引用；后续换例句、模板变化或解析更新不得隐式改写历史导出快照。CardDefinition 可后补，不延后快照边界。

## 理由与取舍

写入外部系统有独立影响范围，不能由站内可撤销选择隐式触发；媒体缺失应可降级。
