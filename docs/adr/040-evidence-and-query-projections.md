# ADR-040 证据、用户裁定与查询投影

## 决策

KnownEvidence 只保存面向 Lexeme 的正向来源事实，source 为 user_asserted / import_anki / import_jpdb。阅读、查词和播放不是认识，SRS 评分不重复写 KE。证据作用域由确定性 `scope_form_key` 表示：Lexeme 级为 `lexeme:`，具体词形为 `form:` 加 NFC 原词形；不 trim、不做大小写或宽窄折叠，空具体词形拒绝。KE 与 LexemeKnowledgeDecision 使用同一派生规则，原始输入另行保存。活动统计后置；算法材料词频索引仍属首版。

用户可追加 known / unknown / clear 裁定与错误来源撤回；裁定按 Lexeme／词形作用域生效，unknown 优先于导入和 SRS，clear 不复活旧人工证据。每个 `(lexeme_id, scope_form_key)` 的决定序号单调递增并有序索引取最新值；导入结果按 `(import_run_id, lexeme_id, scope_form_key)` 唯一，因此不同成功 run 仍可追加独立证据。保留历史不限制用户纠正当前判断。

外部已知词表按独立运行保留原始输入与消解依据，幂等身份包含来源、输入和规则版本；未唯一消解条目隔离报告，不拆成多个已知短单位。运行完整发布前不参与统计；不同快照缺项不自动视为否认，同词重复导入不重复增权。

SRS 信号只从实际复习 Occurrence 及可追溯的同一 Lexeme 累计历史获得资格，不以任意一次合格出现替整份状态背书。原 KP 身份、canonical 聚合和评分对象分开；不能因合并或历史换例句记录转授进度，当前流程不支持换绑 Occurrence。资格不足不影响原 SRS 排程。首版复习估计单列，综合规则另见产品规划未决项。

材料词频稀疏索引、按词证据摘要与 SRS 资格摘要是首版查询基线。常用查询按目标集批量读取，不全扫 KE／ReviewEvent 或整部 sidecar；事实写入同时持久记录失效。动态信号以统一 as_of 计算，最终值若缓存必须有时间有效性。导入／重建按有界批次处理、短事务发布；全量重建追平期间变化后原子切换代次。提取产物另遵守 run 级原子发布闸门：同一 run 仅一方可从 running 提交全部产物并标 done，done 重放返回原结果，提交前崩溃回滚，响应丢失可按原 run 读取。

## 理由与取舍

“某时有过证据”与“现在如何估计”不同。append-only 本身不妨碍时间衰减；避免 srs_matured KE 的理由是复用既有复习事实和算法输入，避免重复维护。用户自报和外部权重不是已校准的掌握概率。

材料 token 频次是覆盖率的权重／分母，不是正向证据。首版显式来源覆盖与相关卡片估计信息有限，但不会把接触过、仅作参考或缺少证据变成掌握结论。词形证据不自动外推到整词，累计历史资格采取保守规则，接受少报以防错误传播。

否决逐次曝光写 KE、仅凭最后一次评分传播全部状态、用同 KP 的另一例句补齐证明、用 `(run, kp, start, end)` 粗粒度唯一键删除合法小节来源，以及用反复全扫历史作为交互查询的默认实现。可重建摘要增加派生存储和失效处理，但把成本移到有界增量写入／后台任务，能保留长历史而不让每次阅读查询承担它。

SQLite WAL 不消除单写入者约束。短事务、持久化重试进度、代次切换与读后写一致性属于正确性要求；缓存范围、批大小和响应预算由测量决定，不提前承诺毫秒级或“规模小可忽略”。[SQLite WAL](https://www.sqlite.org/wal.html)、[事务](https://www.sqlite.org/lang_transaction.html)。SRS 的时间相关信号按实际算法版本求值，[FSRS 上游算法说明](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)仅用于解释，不替代实现记录的算法／参数来源。

## 决策关系与范围

- 保留 ADR-006“已知状态是证据视图”的原则，明确允许可重建物化投影。
- 更新 ADR-011 的“阅读行为积累证据”：活动与已知证据分离，互操作分期不变。
- 保留 ADR-016 原声／TTS 的条件区分及无音频可用性，未实现的听辨来源不占当前枚举。
- 延续 ADR-039 的事实保护／当前状态分离，不引入通用事件溯源框架。
- 讨论稿的汉字身份、orthography 模块与提取恢复不是本次已接受能力，统一登记产品规划 §15；阶段验收／任务包的其他会话迁移不由本文宣称完成。
