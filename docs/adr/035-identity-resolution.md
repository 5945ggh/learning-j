# ADR-035 身份消解条件触发
## 决策

抽取前按原句与 payload 字面量召回；键已存在直接复用，无键但近邻存在才追加一次复用／新建判断，无近邻直接新建。释义不参与身份判定。

## 理由与取舍

形式级身份已把释义变化留在 Occurrence；重新按释义判身份会重开已排除的问题。常驻额外模型调用会放大稠密使用成本。top-k 是召回优化，不能替代校验器。
