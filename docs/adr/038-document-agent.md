# ADR-038 可编辑解析文档与讨论 Agent
## 决策

Study 主区是文档，侧栏是对话。Agent 可交流并通过受控工具编辑文档、检索本地资料、修改有界笔记；取消只追加和一次追问限制。每轮注入当前文档，用户原始消息与运行上下文分离。

## 理由与取舍

用户可能希望缩写、纠错或重组，追加小节不能满足这种协作。工具执行与可见结果需一致，版本检查和 call_id 幂等防止旧上下文或重试破坏文档。

原生工具优先，结构化操作可适配到同一执行器；能力不足明确只读降级。隐藏推理不是业务依赖，必要工具协议与副作用记录独立保留。上下文摘要保留未写入文档的决定；预算耗尽暂停，不默认结束讨论。提取仍是独立、固定输入阶段。
