# ADR-009 可校验内容由算法处理并区分来源
## 决策

形态与词典资源提供可核对的事实；模型提供语境判断与原文子串。偏移、token 对齐、lexeme 和 anchor 派生由后端处理，UI 标明来源。

## 理由与取舍

模型给出的数值偏移可能“合法但错位”，子串未命中能被确定性检测。A 类难以自行验证解释，不能把模型判断标成算法验证。
