# ADR-022 推迟推荐卡片流
## 决策

推迟推荐卡片流、推荐分发队列与知识密度估计；保留学习会话队列与 SRS 到期队列。首版多选仍逐句调用，但普通多选不再隐式跳过讨论。

## 理由与取舍

推荐依赖未验证的独有逻辑；阅读器和主动多选足以支撑当前路径。解析队列与材料会话列表管理用户发起的活动，不承担推荐职责。
