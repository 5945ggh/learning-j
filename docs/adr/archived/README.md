# 已归档 ADR

这里保存已经并入其他决策、或被完整替代的历史 ADR。它们保留编号、决策理由和历史引用价值，但不属于当前行为契约。当前实现应以 [ADR 索引](../../adr.md) 指向的现行条目，以及数据模型、模型契约和设计文档为准。

默认不必读取本目录。以下情况可以读取：

- 需要追溯某条现行 ADR 的来源；
- 需要理解某个方案为何被否决、合并或替代；
- 需要处理迁移、兼容性或历史引用。

归档不是删除。归档 ADR 的 front matter 仍保留稳定 ID 和关系字段；不要把归档文件中的旧决策直接当作当前实现要求。部分被替代但仍有现行内容的 ADR 不放入本目录，而应留在当前目录并标记 `partially_superseded`。

除非任务明确涉及历史维护，不要为了匹配当前行为而改写归档 ADR；应更新现行 ADR 或索引，并保留历史记录。
