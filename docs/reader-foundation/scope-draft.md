# 阅读器基座：近期版本范围

状态：2026-09-14 用户同意开发安排切换，阅读器优先的目标与暂缓范围生效；文件名保留以兼容已有引用。具体支持集合仍按下方限制及产品规划 §15.24 收敛。不是实现完成报告，不替代字段、定位或状态契约；当前派发见 [README](README.md)。

## 目标与完成定义

先交付一个能够日常使用的日语 EPUB/TXT 阅读器：从自己的文件导入，找到书，连续阅读，查词、划线、写注释，关闭后继续。前端通过多轮真实使用收敛，并成为后续学习界面的设计参照。

本版暂缓 AI 生成、讨论、提取及其持久化，暂缓音视频、字幕管线。阅读内容、词典、批注、显示偏好和返回位置仍需持久保存，仅明确指定的开发/测试数据库可显式删除重建；真实素材、词典与用户记录受数据基线及恢复要求保护。返回位置只表示导航位置，不推断读过多少或掌握程度。

成功不是通过原 P2 或做齐未来导航，而是用户愿意用它读自己的书；工程验收同时证明保存和定位可靠。

## 近期范围

| 能力 | 本版拟交付 | 暂缓或限制 |
|---|---|---|
| EPUB | 无 DRM、以文字为主的可重排 EPUB；元数据、封面、目录、章节顺序、段落、图片、ruby、内部跳转 | 固定版式、脚本交互、音视频叠加、DRM、任意出版物的像素级还原不作承诺；EPUB 2/3 具体覆盖由调研样本确认 |
| TXT | 明确编码处理与失败提示；保留段落和空行，长文可读 | 不虚构章节；非 UTF-8 的支持集合随样本确认，不静默损坏文字 |
| 素材库 | 导入、封面及缺封面回退、标题、打开、基本搜索与排序、明确的导入失败/重试 | 无关学习统计、推荐、复杂标签体系暂缓；删除入口须明确对原文件与批注的影响 |
| 阅读 | 图文混排、目录、内部链接返回、字号/行距/主题/内容宽度、返回位置恢复 | 默认先跑通一种连续阅读模式；是否首版同时支持分页由样本与用户反馈决定 |
| 日文排版 | ruby 是核心；竖排在最初原型中验证，避免布局决定封死后续路径 | 竖排正式支持范围待用户确认；不得把验证样例通过写成普遍兼容 |
| 批注 | 划线、跨节点/跨句选区、注释编辑与删除、按材料浏览、跳回原文 | 不自动创建知识点、不触发 AI；跨章选区暂不承诺 |
| 词典 | 接入现有 Yomitan 导入与实时查词；来源、读音、释义、无结果/错误、键盘与焦点返回 | 暂不承诺完整复制 Yomitan 的所有条目呈现与检索选项；保留现有导入信息，富文本支持范围显式列出 |
| 日常使用 | 明确启动方式、导入状态、局部失败恢复、关闭重开可恢复 | 新的安装器、云同步、多用户服务、第二套桌面业务路径暂缓 |

以桌面日常阅读为首要体验，同时验证窄屏不丢内容、不遮挡关键操作。通用组件继续独立于路由与 shell。

## 内容与数据边界

拟采用「阅读内容 + 语言处理内容 + 可验证位置映射」。阅读结构承载图片与排版；规范文本/句子/token 服务查词与未来学习。具体资源模型、映射表示、位置身份、版本策略尚未决定，不在本草案发明字段。

查词应针对当前上下文及时可用。是否整本预分词、按章准备或按需处理，由调研与现有依赖判断；尽量避免等待不相关的学习索引才能打开书。

真实批注开始写入之前，按 ADR-042 登记受支持数据基线并验证备份/隔离恢复。测试库可显式重建；真实素材、词典和用户记录不因原型升级自动删除。重分词不得使已保存的原文定位悄悄漂移。

## 交付节点

2026-09-15 顺序更新：RF-01 已关闭；[RF-02 界面/状态整理](../work-guidance/RF-02.md) 已交付并完成一轮 CR 修复（`113702f`），用户可提前参与素材库与阅读器设计，界面迭代按每轮一个可观察问题继续。RF-02 未新增查词/批注能力，也未将同次布局切换的位置稳定性冒充持久恢复。下一个节点是 [交付安排](delivery-plan-draft.md) 中的可靠恢复与日常使用。

1. **首次可体验阅读**：基于已有调研和必要契约对齐，导入真实 EPUB、打开正文/图片/ruby、切换章节；真实 HTTP 和资源安全一起验证。立即交给用户调整阅读界面，不等待所有设置与恢复完成。
2. **连续使用与恢复**：补显示偏好、返回位置和重启恢复，处理大章与失败反馈；真实数据进入前验收数据基线与隔离恢复。
3. **保存并找回批注**：跨节点/句划线，编辑、删除、跳回；字号变化、图片加载、刷新和进程重启后仍正确。
4. **查词后继续阅读**：现有词典能力接入新正文，不破坏选区、ruby、批注与键盘操作。条件允许可与节点 3 并行。
5. **真实使用与前端打磨**：用目标书籍反复阅读，优先解决影响连续阅读的问题；达到阅读/查词/批注的可靠闭环后评估最小 AI 解析切片。

每个节点拥有必要的前后端修改范围，不再固定拆为三个串行包。视觉反馈从节点 1 起发生，不集中拖到最后。

## 随切片收敛的选择

以下选择由产品规划 §15.24 统一索引，按当前切片需要收敛，不要求一次性回答才能开始首轮体验。

- 目标书籍样本，尤其竖排、插图、脚注和复杂 ruby 的比例。
- 第一版默认滚动还是分页；竖排是否为日常使用的必需条件。
- 词典需要呈现到什么程度：纯文本释义是否可用于过渡，图片与结构化释义哪些必须保留显示。
- 自用版本对启动、备份、删除素材和批注导出的最低要求。
