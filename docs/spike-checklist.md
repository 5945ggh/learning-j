# LearningJ 实验清单

> 本文只定义需要实证的问题、方法与判定，不重复实体契约或阶段验收。未决事项的唯一索引是 [产品规划 §15](LearningJ-plan-v5.md#15-未决事项)。
> 2026-09-08 已按学习会话／Agent／历史保护更新测量口径，见 [变更指引](changes/2026-09-08-study-session-agent-history.md)。以下是待做实验，不代表结果已产出。

## 0. 共用底座

建立 50–100 句人工评测集。起步构成可为口语 25、书面语 15、文化互文 10；至少五组远距离复现配对散布其中，覆盖不同用法。标注分两步，避免按 DSL 能力反向抹平缺口：

1. 自然语言标记期望知识点、salience 和不应抽取的说明。
2. 独立标记是否能用当前 shape/payload 与 DSL 表达。

reference 是用户意愿，不由标注者按文化内容类别预判。通用指标包括抽出率、误抽率（合理但未预期单列）、复用率和抽象层级漂移率。所有实验记录模型、prompt、DSL、分析器词典和文档 revision 来源，使用新版本化的结果文件。

## 1. 提取执行路径

对同一固定 AnalysisRevision 分别做续轮与独立提取，比较误抽、复用、对过时对话内容的误引用、成本和延迟。输入文档必须相同，不能把 Agent 修改前后两个版本误当成路径对照。

独立路径始终必须支持。续轮若显著过抽、降低复用或误用旧正文，调整默认路径；当前规范只保留它作为可选快路径，不依赖缓存。

## 2. 模式语言的可校验性与身份稳定性

先用 JLPT 种子与前 20 句建立候选库，在剩余 30–80 句比较两条提取路径。分别统计：

- 字面量顺序、槽位定位、POS/category 相容、可校验 form 的通过率；不可判断 form 另计。
- 零槽位对应单 lexeme 的 lint 分布；entity 不参与上述身份校验的占比。
- model_chosen 和 validation_failed 两种 opaque 率，分开呈现。
- 同一现象的键碰撞、复用和 category/form 抽象层级漂移。
- 近邻存在但键不存在、需要额外身份消解调用的比例，结合实验 9 折算成本。
- 完整 surface 与槽位 surface 的范围关系、重复子串下的绑定歧义；不能只测每条 Occurrence 恰好一个 Span。

版本化交付物：

1. `grammar_enums_v1.yaml`：category/form 覆盖、Clause 与 V 的边界、none 的准确语义。
2. `validation_strictness_v1.json`：各规则 error/warning/skip 级别。
3. `grammar_decision_table_v0.md`：常见语法形式推荐与活用限定规则。

这些文件尚未冻结；后续提取实现的依赖安排由阶段迁移负责人同步。当前临时规范以 prompt-contracts §7 为准，不因有结构化 schema 就假定覆盖率已足够。

## 3. 跨句上下文与画像效果

对远距离复现句比较注入与不注入既有 KP／笔记，测重复展开、差异指出和过度省略。MVP 只验证词汇锚召回；若人工强制注入语法 KP，单列为实验条件，不宣称自动匹配已实现。

加入用户纠正画像、要求不再记录某偏好的用例，检查工具修改与后续上下文一致。作品笔记与画像不替代“已经讲过”的确定性检索。

## 4. 子串与槽位定位

在原句执行 find_all 并与 sidecar 对齐，分别统计 aligned/partial/ambiguous/unaligned 与未命中 surface；不合并为一个失败率。

分类辞書形替代表层、补省略助词、拼接不连续文本、错误前缀和重复命中。完整出现范围与槽位绑定分开测：普通 Span 可保留 unaligned，模式绑定必须符合校验要求；多处完整命中与无法唯一确定的局部槽位也分开统计。

同时检查部分候选失败仍保留有效产物、全部候选无效才整体重试的规则。偏移由模型直接生成的方案不再测试，决定见 ADR-009。

## 5. 模块默认组合

比较九项全开和候选子集的长度、内容取舍与 ExtractionSection.kind 分布。kind = 九个模块 + takeaway + qa；映射属于某次提取的输入版本，不是 Agent 修改后依然有效的文档标签。

关注被关闭模块是否换名出现在其他小节，决定 UI 是否用“侧重”等软约束措辞。用用户文字描述的听感困惑验证 colloquial 的覆盖；不以此声称模型处理过音频。

## 6. 小节切分与编辑后的引用

对真实长解析测试 heading/paragraph/fallback_single 降级及切分合理性，评估卡背是否过粗或解释被劈开。

再执行缩写、扩写、删除、合并、移动和跨模块重组，检查新 manifest 的顺序与小节身份。固定旧 revision 提取后继续编辑新版本，验证卡片旧引用不变、旧映射不套用新正文、清理不删除被引用版本。

## 7. 显著性

对最终提取文档而非最初生成稿统计 primary 数量及与 takeaway 的一致性。讨论删改知识内容后，总结应同步；缺少 primary 为弱信号，不靠重复提取制造不存在的总结。

salience 仅测内容显著性、确认排序与新卡待建优先级；所有模式新卡都须用户明确 srs 选择，不再测 batch/background 默认自动排程。reference 不作为模型分类目标。

## 8. 联网检索

问题保留，MVP 不做此实验。将来对文化互文等场景比较联网检索影响；本地词典／KP 查询属于 Agent 本地工具，不等于 retrieval_enabled 联网开关。

## 9. 成本与延迟

分别记录初始生成、每个讨论运行中的模型／工具循环、提取、条件身份消解的输入输出 token、调用数和延迟。单句一次首稿与多轮编辑分别报告，不用平均 turn_count 掩盖长尾。

推算每天 30–50 句的稠密使用范围；比较普通多选与 explicit automatic，说明队列并发和模型预算如何影响等待。预算阈值验证只暂停执行，不触发未经用户选择的讨论结束。

另记录当前文档、消息、工具协议、有效版本与派生资源的字节数，区分必要历史和重复注入冗余，作为草稿撤销／日志保留参数的依据。

## 10. Agent 可靠性与上下文裁切

新口径补充，不隐含某个阶段已经交付。跨目标 provider 验证原生工具或结构化操作适配：

- 读后改、连续多工具、失败回传、版本过期刷新、call_id 重试幂等、取消后已提交部分的呈现。
- 超限笔记写入、错误 scope、读取修改后的画像与用户撤销。
- 历史注入移除后当前文档只出现一次；摘要保留用户否定、偏好与尚未解决的问题。
- 工具调用／结果成组裁切，续接成功；不依赖隐藏推理作为领域数据。
- 只读问答降级明确，不能把未执行的编辑描述成成功。

结果用于产品未决项 15 的能力矩阵与预算／保留默认值。判定依据是工具实际结果、文档版本和上下文内容，不是模型声称“已修改”。

## 本轮不测

GiNZA／依存学习效用、推荐器、TTS 选型、SRS 算法比较、PDF 原生渲染、多句联合会话和完整知识图谱。素材类型、code point 与独立提取可用性属于既定契约，不通过实验重开。
